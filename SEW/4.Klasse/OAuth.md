OAuth (Open Authorization) ist eine standardisierte, sichere API-Autorisierung für Desktop-, Web- und Mobile-Anwendungen. Aktuelle ist Version 2.0.
z.B.: Einen Client wird der Zugriff auf den Resource-Server (REST-API) durch einen Authorization Server gewährt, ohne geheime Details seiner Zugangsdaten dem Resource-Server preis zugeben.
