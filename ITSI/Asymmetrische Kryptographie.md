## gcd / ggt

ggt(84, 30) = ggt(24,30) = ggt(24,6) = ggt(0,6) = 6
Das passiert mit a % b = a_2 (wobei a die größere Zahl ist), dieser vorgang endet wenn a_2 = 0
```python
print("a = ", end="")
input1 = int(input())

print("b = ", end="")
input2 = int(input())

a = input1
b = input2

while True:
    aTwo = max(a,b)
    bTwo = min(a,b)

    if aTwo != 0 | bTwo != 0:
        a = aTwo % bTwo
        b = bTwo
    else:
        break

solution = max(a,b)
print(f"ggt({input1},{input2}) = {solution}")
```
