# Newtonsche Axiome

## 1. Axiom / Trägheitsgesetz

Jeder Körper bleibt in Ruhe oder gleichförmiger Bewegung, solange keine Kraft auf ihn wirkt.

## 2. Axiom / Dynamisches Grundgesetz

Kraft = Masse x Beschleunigung
$$F = m \cdot a$$
$[F] = kgms^{-2} = 1 N$
## 3. Axiom / actio = reaction

Zu jeder Kraft gehört eine gleich große entgegengesetzte Kraft.
$$F_1 = - F_2$$

## Inertialsysteme

Ein System, in dem das Trägheitsgesetz gilt nennt man Inertialsystem.

## Masse, Gewicht, Dichte

Gewicht = Masse mal Erdbeschleunigung
$$G = m \cdot g$$

Dichte = Masse pro Volumen
$$\rho = m / V$$
