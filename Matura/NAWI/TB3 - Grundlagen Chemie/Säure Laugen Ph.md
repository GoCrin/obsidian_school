# Protolyse

Eine chemische Reaktion bei der Protonen von einem Stoff an einen anderen gegeben werden. Dies passiert in der Form von **positiv geladenen Wasserstoffionen**.

# Säuren

Sind Stoffe die Protonen abgeben können (Protonendonator). Bilden mit Wasser Hydroniumionen.

# Basen 

Sind Stoffe die Protonen aufnehmen können (Protonenakzeptor). Bilden mit Wasser Hydroxidionen.

# Neutralisation

Wenn eine Verbindung weder sauer noch basisch ist, nennt man sie neutral.

## Salze

Bei Neutralisation von Säuren und Basen entstehen Salze. Alle Salze sind Ionenverbindungen.

# pH-Wert

Lösungen die Ionen enthalten, leiten elektrischen Strom. Die Leitfähigkeit steigt mit der Ionenkonzentration. 

H₂O + H₂O → H₃O⁺ + OH⁻

Das Gleichgewicht ist fast ganz auf der linken Seite.

Man hat gemessen, dass in einem Liter Wasser 10-7 Mol Wassermoleküle reagieren. Heißt, dass je 10-7 Hydroniumionen (und Hydroxidionen) in einem Liter Wasser sind. Der ph-Wert ist wie folgt definiert.

$$pH = -log_{10}(H_3O^+)$$
Weitere Formeln:

$$pOH = -log_{10}(C_{OH^-})$$
$$pH + pOH = 14$$
## Beispiel 1

geg.
$1g\ HCl$
$5L\ H_2O$

$HCl$: $1 + 35,45 = 36,45g/mol$ => $\frac{1g}{36,45g/mol} = 27,4mmol$
$$pH = -log_{10}(\frac{27,4mmol}{5L}) = 2,26$$
