# Arbeitspakete


|                                                                                                                                                        |     |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | --- |
| Als Spieler möchte ich mich mit WASD bewegen können um die Umgebung erkunden zu können                                                                 |     |
| Als Spieler möchte ich, mittels Maus meine Waffen zielen können um Gegner besser besiegen zu können.                                                   |     |
| Als Spieler möchte ich, wenn ich das Spiel starte ein Menü angezeigt bekommen um vor dem Spielen, Einstellungen änderen zu können.                     |     |
| Als Spieler möchte ich nach dem Tod meines Character die Möglichkeit haben eine neue Runde zu starten.                                                 |     |
| Als Spieler möchte ich über eine Szene für Einstellungen, die Lautstärke des Spiels bearbeiten um beim Spielen keinen Gehörschaden zu bekommen.        |     |
| Als Spieler möchte ich, dass bei jeder Runde die Welt neu generiert wird um das Spiel langfristig genießen zu können.                                  |     |
| Als Spieler möchte in einigen Räumen auf Gegner treffen, welche ich besiegen kann um im Spiel voran zu schreiten.                                      |     |
| Als Spieler möchte ich für das Besiegen von Gegnern belohnt werden um im Spiel ein Gefühl des Fortschritts zu haben.                                   |     |
| Als Spieler möchte ich durch Glück in Räumen auf Gegenstände treffen, welche ich mit Geld kaufen kann um die zukünftigen Räume leichter zu bewältigen. |     |
