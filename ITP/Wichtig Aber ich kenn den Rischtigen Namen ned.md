# Projektinitiierung (von der Projektidee zum Projektauftrag)

## Umfeld-analyse

|        | fachlich                                     | sozial                   |
| ------ | -------------------------------------------- | ------------------------ |
| intern | interne Richtlinien                          | Mitarbeiter              |
|        | Vorhandene Technik                           | Betriebsrat              |
|        | Restrukturierung (Änderungen am Organigramm) | GF (Geschäftsführung)    |
|        |                                              | Team                     |
| extern | Klima                                        | Konkurrenz / Mitbewerber |
|        | Wettbewerb (Neue Produkte)                   | Politiker                |
|        | Rechtliche Vorschirften                      | Kunden                   |
|        |                                              | Umweltorganisationen     |
|        |                                              | Medien                   |

Die **soziale** Spalte kann als Input für die Stakeholder-analyse verwendet werden.
Die **fachliche** Spalte kann als Input für die Risiko-analyse verwendet werden.
