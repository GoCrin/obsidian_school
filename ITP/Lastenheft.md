Lastenheft: 
* Was?
* Auftraggeber (Firma) publiziert was sie brauchen
* Ziele (Smart)
* Anforderungskatalog
	* Funktionale Anforderungen
	* Nichtfunktionale Anforderungen



Pflichtheft: Wie? Andere Firmen schreiben zurück wie sie das Umsetzen würden

Pflichtheft -> Anforderungsanalyse -> Lastenheft (Formelle Infos, Überblick, Zielgruppe & Ziele, ...) -(Complience)-> ...

Funktionale Anforderungen (so wie user stories):
* Benutzerinteraktionen

Nicht Funktionale Anforderungen (passiert ohne user input -> durch userstories nicht darstellbar):
* Technologie
* Security
