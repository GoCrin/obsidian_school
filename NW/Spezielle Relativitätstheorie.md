### Zeitdilatation
$t = \frac{2x}{c}$
$t_{bewegt} = \frac{2z}{c}$
$z^2 = x^2 + y^2$
$t_{bewegt} = \gamma * t$
$\gamma$ ... lorentz factor
$\gamma = \frac{1}{\sqrt{1- \frac{v^2}{c^2}}}$

#### Beispiel
$S = 10L_j$
$v = 0.8 * c$

$\gamma = \frac{1}{\sqrt{1 - 0.8^2}} = \frac{5}{3}$

$t_E = \frac{2s}{v} = \frac{20L_J}{0.8 * c} = 25 a$ ... a -> Jahre
$t_R = \frac{t_E}{\gamma} = \frac{3}{5} * \frac{20L_J}{0.8 * c} = 15a$

### Längenkontraktion

$l_E = \frac{l_R}{\gamma}$
