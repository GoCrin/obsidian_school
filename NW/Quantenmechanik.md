# Photoeffekt

Wenn $E_{\gamma} > W$
$E_{e^-} = E_{\gamma} - W$

$h = 6,63 * 10^{-34} Js$
$W_{Zn} = 7*10^{-19} J$ ... Austrittsarbeit von Zink
$E_{\gamma} = h *f$
$f = \frac{c}{\lambda}$
$$E_{550nm} = \frac{h * c}{\lambda} = \frac{6,63 * 10^{-34} * 3 * 10^8 Jm}{550 * 10^{-9}}= 3,6 * 10^{-19} J < W_{Zn}$$
$$E_{250nm} = \frac{h * c}{250 * 10^{-9}} = 7,956 * 10^{-19} J > W_{Zn}$$
Austrittsarbeit ist wichtig für PV (soll minimiert werden)
$E_{KIN_E} = E_{\lambda} - W$ ... für $E_{\lambda} >= W$
$E_{KIN_E} = 0$

# De  Broglie - Welle Teilchen Dualismus

## Tennisball

$\lambda = \frac{h}{m*v}$

Masse $= 57g ~ 10^{-2}kg$
$\lambda = 10^{-34}m$ winzig
Keine Wellen Eigenschaften messbar! Wellenlänge <<<<< Objekt

## Elektron

Masse $= 10^{-30}kg$
$\lambda = 10^{-10}m$ relevant
Beugung möglich! Wellenlänge ~ Atomabstand

## Elektronen Mikroskop
Mikroskop kann maximal die Wellenlänge auflösen
Sichtbares Licht: $\lambda$ von 400-800nm
$\lambda_{e^-}$ << $\lambda_{Licht}$
