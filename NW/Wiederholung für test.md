# Formelsammlung
## Spezielle
$p = m * v$
$\gamma = \frac{1}{\sqrt{1 - \frac{v^2}{c^2}}} >= 1$, v -> c => $\gamma$ -> $\infty$ 
$t_{Ruhe} = t_{Bewegt} * \gamma$; $t = t_{Bewegt}$; $t' = t_{Ruhe}$; $t_{Bewegt} < t_{Ruhe}$ 
$l_{Ruhe} = l_{Bewegt} * \gamma$; $l_{Bewegt} < l_{Ruhe}$
$m_{Bewegt} = m_{Ruhe} * \gamma$; $m_{Bewegt} > m_{Ruhe}$
$E = m * c^2 = m_0  \gamma * c^2$

$u = u' + v$ ... Gallilei Transformation
$u = \frac{u' + v}{1 + \frac{u * v}{c^2}}$ ... Lorentz Transformation

## ART (muss man nur anwenden können)

$R_s = \frac{2 G M}{c^2}$ ... Schwarzschild Radius
$\frac{\Delta f}{f} = \frac{g * h}{c^2}$ ... Gravitations Rot Verschiebung
$E = h * f$ ... Energie eines Photons (h ... Planck Konst.)
